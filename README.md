## Descripción

**Huellitas Oaxaca** es una aplicación web desarrollada para facilitar la adopción responsable de perros y gatos en el estado de Oaxaca.

La plataforma permite que los usuarios consulten mascotas disponibles para adopción, conozcan su información, envíen solicitudes de adopción y realicen donaciones para apoyar a los refugios participantes. Además, cuenta con un panel de administración para gestionar mascotas, refugios, solicitudes y usuarios.

---

## Problemática

Actualmente, muchas mascotas rescatadas permanecen durante largos periodos en refugios debido a la falta de una plataforma que concentre la información sobre adopciones. Por otro lado, las personas interesadas en adoptar suelen buscar información en diferentes redes sociales, donde las publicaciones se pierden rápidamente o no contienen toda la información necesaria.

**Huellitas Oaxaca** busca centralizar este proceso mediante una plataforma web que facilite la adopción responsable y promueva el apoyo a los refugios mediante donaciones.
